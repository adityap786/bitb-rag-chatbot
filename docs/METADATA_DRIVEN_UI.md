# Metadata-Driven UI & Pipeline

## Overview
All onboarding flows, UI, and pipeline steps are metadata-driven, reading from tenant config (features, branding, plugins, etc.). This enables per-tenant customization and rapid extensibility.

## Features
- UI and pipeline logic read from tenant_configs and features
- All flows are dynamic and extensible
- All infra is open source or free

---

This enables world-class flexibility and customization for all tenants.
