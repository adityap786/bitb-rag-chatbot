# Open Source Stack Policy

## Overview
All components and services in this system are open source or free (local/cloud). No paid or closed-source dependencies are used in production.

## Stack
- **Database:** Supabase/Postgres
- **Vector Store:** pgvector
- **Cache/Queue:** Redis, BullMQ
- **Tracing:** OpenTelemetry, Jaeger
- **Testing:** Vitest
- **API/Backend:** Next.js, Node.js
- **Frontend:** React
- **CI/CD:** GitHub Actions (free tier)
- **Logging:** ELK, Loki, or similar

---

This ensures cost efficiency, transparency, and long-term sustainability.
