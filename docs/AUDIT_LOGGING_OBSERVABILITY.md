# Audit Logging & Observability

## Overview
All pipeline steps, admin actions, and plugin events are logged with tenant context for audit and debugging. Logs are centralized and queryable using open source tools (e.g., ELK, Loki).

## Features
- Log all actions with tenantId, user, and event type
- Centralized, queryable logs
- All infra is open source or free

---

This ensures secure, auditable, and observable operations for all tenants.
